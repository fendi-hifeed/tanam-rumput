# Illustration & Asset Prompts — PT Lampung Tanam Rumput (PLTR)

Ilustrasi untuk website PLTR. Bisa dihasilkan via Figma (figma.com/ai), DALL-E, Midjourney (dengan flag `--style SVG` atau `--format svg`), atau SVG generator. Semua illustration harus dalam gaya **clean geometric, earthy, editorial** — bukan clip art atau stock look generik.

---

## Brand Design Language

| Aspek | Direction |
|---|---|
| **Style** | Clean geometric / flat illustration. Minimalist, confident, editorial. Like a high-quality annual report or nature journal — not a children's book or NGO flyer |
| **Palette** | Forest Green `#2F4A2A` · Soil Brown `#7A4E2D` · Harvest Gold `#C9A961` · Cream `#F5EFE3` · Ink `#1B1B17` |
| **Line weight** | Consistent, 1.5–2px strokes. No sketchy or hand-drawn strokes |
| **Shapes** | Geometric — circles, rounded rectangles, straight lines. Organic shapes only where they represent natural elements (leaves, soil, roots) |
| **Typography pairing** | Fraunces (display serif) + Inter (body sans) |
| **Mood** | Grounded, trustworthy, professional, warm. Feels like a well-designed agricultural investment prospectus, not a charity brochure |
| **What to AVOID** | Cartoon plants, cartoon characters, overly whimsical illustrations, generic stock leaf icons, clip-art grass, emojis, drop shadows, gradient meshes, 3D renders, tropical beach vibes, corporate blue |

Create a clean topographic line pattern using 8–12 curved horizontal lines that vary in:
- Opacity: 5% at top → 25% at bottom

## Technical Notes for Asset Production

### Preferred formats
| Asset | Format | Notes |
|---|---|---|
| All illustrations | SVG | Preferred — clean, scalable, fast-loading |
| Icons | SVG | 24x24 or 64x64 viewBox, single color or two-color |
| Diagrams | SVG | Must work at 1200px wide down to 320px mobile |
| Hero BG | SVG or PNG 2x | If PNG, use WebP, max 200KB |
| All assets | PNG fallback | For Figma/Midjourney outputs, convert to SVG via Vectorizer.ai or Figma |

### Naming convention
```
/public/illustrations/
  value-chain-diagram.svg
  theory-of-change.svg
  hero-background.svg
  pillar-icon-land.svg
  pillar-icon-women.svg
  pillar-icon-biomass.svg
  before-after-land.svg
  problem-infographic.svg
  metrics-charts.svg
  beneficiary-placeholder.svg
  topographic-pattern.svg
  field-scene.svg
  partnership-cta.svg
```

### Accessibility
- All SVG/illustration elements must have descriptive `aria-label` or `<title>` + `<desc>` elements
- Do not use illustrations as the only way to convey information — always have text backup
- Color contrast must meet WCAG AA for any text overlaid on illustration backgrounds

### Performance
- Total illustrations budget: < 500KB combined (all SVGs)
- Avoid embedded raster images in SVGs
- Use `display: none` or `visibility: hidden` for decorative elements if they should not be read by screen readers
- Hero background SVG should be max 50KB
